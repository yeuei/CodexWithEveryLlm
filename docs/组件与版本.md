# 组件与版本

## 组件职责

- **总仓库**：面向人类用户的入口、架构说明、快速开始和兼容版本清单。
- **Local Agent skill**：本地 Agent 的执行规则，以及 Dashboard 的启动、状态检查和停止能力。
- **交接项目**：事件、PR、任务文件、历史提交和运行证据的真实来源。
- **协议模板**：可复用的任务、报告、配对和状态机模板，不包含具体项目数据。

## 推荐组合

正式发布时，为每个组件填写稳定版本：

| 组件 | 仓库 | 版本 |
| --- | --- | --- |
| Local Agent skill | [yeuei/agent-github-project-executor-skills/main](https://github.com/yeuei/agent-github-project-executor-skills/tree/main)；承载 skill 与 Dashboard 部署子能力 | `99b91e9` |
| 交接项目 | [yeuei/gpt---github---codex](https://github.com/yeuei/gpt---github---codex) | 待发布 tag/commit |
| 协议模板 | [yeuei/template_chatgpt_github_codex](https://github.com/yeuei/template_chatgpt_github_codex) | 待发布 tag/commit |

版本清单比 submodule 更适合本项目：克隆总仓库即可阅读文档，不需要额外初始化子模块；组件仍可独立修复、测试和发布。

兼容组合至少要求：skill launcher 能执行 `start/status/stop`；交接项目提供
`/api/status`、`/api/bindings` 和 binding.v1；模板保持通用，不含项目专属 URL、
命令、profile 或 token。正式发布时把三者 tag/commit 填入本表，并在升级说明中注明
不兼容变更。

安装该 skill 后，Agent 使用其中的 `references/dashboard-runtime.md` 和
`scripts/dashboard_runtime.py` 自行启动、检查、停止或重启 Dashboard：

```text
python /path/to/agent-github-project-executor-skills/scripts/dashboard_runtime.py \
  status --project-root /path/to/gpt---github---codex
```
