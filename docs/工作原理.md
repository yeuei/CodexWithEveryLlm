# 工作原理

```text
人类用户
   ↓ 选择项目与对话
ChatGPT Web ──创建任务/配对链接──▶ GitHub 交接仓库
                                      │
                                      ▼
                              Local Agent + Dashboard
                                      │
                                      ▼
                              PR、事件与任务历史
```

总仓库只描述组合关系。真实事件和历史进度保存在交接项目中；协议模板提供通用格式；Local Agent skill 提供本地执行和 Dashboard 的调度入口。

任务进度按事件对应的历史提交恢复。每个画布节点显示该提交时的状态，并可另行查看当前最新状态；如果没有可靠历史快照，界面应明确标注未知，而不是推断完成。
