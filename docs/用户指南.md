# 用户指南

## 你可以用它做什么

你可以让 ChatGPT Web 提出任务，让本地 Agent 执行任务，并通过 GitHub 保存交接过程、审批记录、PR 变化和任务进度。

Dashboard 是可观察界面：它展示当前交接仓库、项目和 PR 的事件画布，也允许查看某个节点当时的任务进度，而不是只显示任务文件的最终状态。

安装 Local Agent skill 后，由 Agent 根据当前交接仓库定位 runtime 并自动部署 Dashboard；用户只需在首次启动时确认目标仓库、端口和本机授权。skill 会提供启动、状态、停止和重启入口，状态检查同时核对 `/api/status` 与实际监听实例。

## 一次交接包含什么

- 一个交接仓库：保存双方共享的事实。
- 一个具体项目或 PR：标识正在处理的工作。
- 一个 Local Agent 和本地对话：接收本地执行任务。
- 一个 ChatGPT Web 对话：提出任务并查看结果。
- 一个稳定绑定：把仓库、分支、PR、Agent 和两端对话准确连起来。

## 安全边界

GitHub 负责传递事件和保存记录；Agent 和 Web 对话各自通过独立授权控制。没有明确绑定或发生冲突时，事件应进入人工处理，不应广播给多个 Agent。
