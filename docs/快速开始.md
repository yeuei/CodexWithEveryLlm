# 快速开始

先准备三个独立组件：总仓库用于阅读和版本组合；协议模板用于初始化交接仓库；从 [yeuei/agent-github-project-executor-skills](https://github.com/yeuei/agent-github-project-executor-skills) 安装 Local Agent skill。不要把它们作为 submodule 一起克隆。安装 skill 后，Agent 会从当前交接仓库和其本地配置推导 runtime 并自动部署 Dashboard。

## ChatGPT Web 侧

1. 创建交接仓库和初始任务。
2. 生成一次性配对链接。
3. 将链接交给要参与的 Local Agent。
4. 等待 Agent 认领并确认绑定。

## Local Agent 侧

1. 打开配对链接并核对仓库、分支和 PR。
2. 认领绑定，确认本地 Agent 标识和具体本地对话。
3. 启动 Dashboard，检查绑定状态和事件流。
4. 只处理精确路由到当前绑定的事件。

绑定完成后，Dashboard 中应看到 `active` 状态；若显示 `conflict`、`expired` 或目标不匹配，停止发送并回到 ChatGPT Web 重新生成邀请，不要重试旧 token。

## Dashboard

Dashboard 由 Local Agent skill 调度。使用 skill 提供的启动、状态、停止和重启能力；健康检查会核对 `/api/status`、目标仓库路径和实际监听进程，不会泄露配对 token。端口被占用时选择明确的备用端口，不要终止未知进程。
