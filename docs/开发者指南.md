# 开发者指南

## 修改边界

协议模板不得写入用户项目数据；交接项目不得把某个用户的仓库或对话信息写入通用 skill；总仓库只维护说明、组合关系和发布记录。

## 发布流程

1. 分别在三个组件仓库完成测试和发布。
2. 为每个组件创建稳定 tag。
3. 更新本仓库的组件版本表和兼容说明。
4. 在总仓库发布说明中记录变更和升级注意事项。

## Dashboard 调度

Local Agent skill 通过统一入口调度 Dashboard，至少提供启动、状态和停止三类操作。状态检查应返回可读的健康结果、服务地址和进程信息，不输出 token、完整配对链接或私密对话内容。

skill 只负责安装、调度和观测；Dashboard/runtime 代码与 SQLite 事件状态仍归交接项目维护。推荐使用 skill 的 launcher 指向目标项目绝对路径，不复制源码，也不使用需要额外初始化的 git submodule。`status` 应探测 `/api/status`，而不是仅凭进程存在判断健康。

本机 skill 安装入口：

```text
/Users/fy/.codex/skills/local-agent-github-project-executor-v2
```

启动、状态和停止：

```text
python /Users/fy/.codex/skills/local-agent-github-project-executor-v2/scripts/dashboard_runtime.py start --project-root /path/to/gpt---github---codex
python /Users/fy/.codex/skills/local-agent-github-project-executor-v2/scripts/dashboard_runtime.py status --project-root /path/to/gpt---github---codex
python /Users/fy/.codex/skills/local-agent-github-project-executor-v2/scripts/dashboard_runtime.py stop --project-root /path/to/gpt---github---codex
```

skill 的已确认 GitHub 远端是 [yeuei/agent-github-project-executor-skills](https://github.com/yeuei/agent-github-project-executor-skills)；具体版本以该仓库发布的 tag/commit 为准。
